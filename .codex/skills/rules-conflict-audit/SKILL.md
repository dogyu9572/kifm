# 규칙 충돌 감사

## 목적

Codex 규칙을 작고, 실행 가능하고, 구현 판단에 도움이 되는 상태로 유지한다.

## 감사 순서

1. 요청을 설명, 국소 수정, 다중 파일 기능, UI 변경, DB/데이터 변경, 환경 작업으로 분류한다.
2. `AGENTS.md`에서 적용되는 규칙 그룹을 찾는다.
3. `금지 > 우선 > 허용 예외` 순서로 충돌을 판단한다.
4. 사용자 요청 변경과 부가 개선을 분리한다.
5. 필요한 최소 규칙 조정 또는 코드 조정을 제안한다.

## 출력

- 치명도 순 발견 항목
- 충돌하는 지시와 우선 적용할 규칙
- 필요한 사용자 확인 사항
- 최소 패치 제안

## 제약

- 실제 모호성을 줄이지 않는 새 절차를 만들지 않는다.
- 사용자 요청 범위 밖으로 확장하지 않는다.
- 여러 중복 규칙보다 하나의 명확한 규칙을 선호한다.
