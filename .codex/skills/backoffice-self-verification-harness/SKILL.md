# 백오피스 자기검증 하네스

## 핵심 점검

1. 라우트 진입: 페이지가 열리거나 예상된 인증/권한 동작이 명확하다.
2. CRUD 왕복: 목록 -> 생성/수정/상세 -> 저장/취소 -> 목록 흐름을 확인한다.
3. 필터 유지: keyword/date/status/per_page/page query 상태가 이동 후에도 유지된다.
4. 유효성 실패: 필수값/형식 오류가 표시되고 버튼 상태가 고착되지 않는다.
5. 자산 분리: 변경한 Blade에 인라인 style/event/script가 없다.
6. 정적 품질: 변경한 PHP는 `php -l`, 가능한 경우 관련 JS/CSS도 점검한다.

## 브라우저 확인이 어려울 때

- 직접 실행하지 못한 시나리오를 정확히 보고한다.
- 추측하지 말고 route/link/form/action 정적 점검을 우선한다.
- 사용자가 이어서 확인할 수 있는 명령이나 URL을 1~2개 제시한다.

## 최종 보고 형식

- 검증한 항목
- 통과/실패 결과
- 미실행 항목과 사유
- 남은 위험도: 낮음/중간/높음
